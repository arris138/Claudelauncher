What moves

Eight changes, all of them things the two modes currently disagree about.

Mode toggle
Lives at the far left next to the wordmark in both stages. Today IDE puts it left and Launcher hides it inside an IDE button on the right, so the control you press to swap modes moves 1000px between presses.
Top bar buttons
One family, top right, in both stages: same 24px height, border, radius and uppercase type, with the glyph in steel until hover. + Project is the only one wearing the rust fill, because it's the only one that creates something. Today Cmd and PS are rust slabs, the gear is a bare icon and Add Project is amber text on nothing.
Session rail
Always mounted, both stages. Browsing projects no longer means losing sight of what's running, and clicking a session card jumps straight to its terminal.
Add project
Lives in the top bar, so it's in reach from the terminal as well as the project list. A second door into the same AddProjectDialog sits at the top of the Jack In picker as New project…, which creates the project and jacks into it in one move.
Row actions
Every project row offers both launch paths: Terminal spawns the Windows Terminal tab it always did, Jack in opens it as an IDE session. Edit and remove stay where they are.
Live markers
A green Live chip on any project that already has a session, with a count when there's more than one. That's the fact you currently have to switch modes to learn.
Status bar
Merged. Session counts from IDE on the left, version and the update button from Launcher on the right, one bar across both stages.
Skin
Launcher drops Tailwind's slate-and-amber for the Chrome & Rust tokens already in src/theme/chromeRust.css. No new palette, no new faces.

Two calls left to make

This mock assumes an answer to each. Say the word if you want the other one.

  1. Does the rail belong in Launcher mode? The mock assumes yes, so both stages share one frame. The alternative is Launcher keeping a full-width screen with no rail, just repainted in this theme, which is a smaller change to App.tsx.

  2. How deep does project editing go inside IDE mode? The mock puts the full table, edit, remove and flags in the Launcher stage, one toggle away. The alternative is a rail section listing every project under the live sessions, so you never change stages at all.
